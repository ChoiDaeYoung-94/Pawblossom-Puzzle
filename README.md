# Pawblossom Puzzle

핍과 함께 서로 다른 풍경을 여행하고 정원을 가꾸는 귀여운 매치3 퍼즐 게임입니다. 한국어를 기본으로 영어도 지원하며, TypeScript + Phaser + Capacitor로 Android 구글 플레이 출시를 준비합니다.

## 현재 개발 상태

**500레벨·25풍경을 갖춘 개발 시제품(v0.1.7)**입니다. 기존1–100의 데이터·서명을 유지하고101–500을 추가했습니다. 자동 검증·브라우저 검수와 실제 단말·사용자 감각·운영 광고/결제·스토어 검증은 구분합니다. 출시 완료 상태는 아닙니다.

- 지도 중심 진입,20판마다 큰 풍경 변화, 구간 이동과 내부 스크롤의 부분 연출·입체 발판·현재 위치 안내
- 비정형8×8 보드, 연쇄 제거·낙하·힌트·막힌 보드 재배치, 낙엽·상자 목표와 특수 블록/조합
- 첫 완료 별·코인, 진행 중 일반 회차 저장/이어하기, 손상 저장 보호·이전 확정 저장의 복구 사본
- 꽃밭·연못·쉼터와 핍 돌봄/성장·소품, 후반 여행 정원10작품·20스타일 및 다음 목표 연결
- 자체 풍경·정원 그림, 캐릭터 관절/눈·매치 반응, 특수·연쇄 연출과 모션 감소·화면 이탈 정리
- 자체 배경음12곡과 효과음8종, 구간별 음악·마디 전환·개별 음소거·비활성 중단/복구
- 한국어·영어, 터치/드래그·키보드 조작·접근성 안내, testing 전용 판 선택·정원 체험과 정상 보상 분리

아이도 즐길 수 있지만 주로 성인이 편하게 즐기는 방향입니다. 첫 출시 준비 국가는 한국·미국이며 실제 대상 연령·광고/결제·정책/스토어 조건은 출시 전에 검증합니다. 광고 제거 계획은 한국3,000원/미국US$2.50 일회성 구매 후 전면·보상형 포함 모든 광고 제거입니다. 아이템 판매 확대는 기획 범위이며 실제 상품 등록/운영 결제 완료가 아닙니다.

## 실행과 검사

Node.js22 이상을 사용합니다. PC 이전 후 도구가 PATH에 없으면 [새 PC 환경](docs/new-pc-environment.ko.md)을 확인해 주세요.

```sh
npm ci
npm run dev
npm test
npm run build
npm run build:test
```

일반 웹 빌드에는 시험 도구를 넣지 않고 testing 빌드에만 시험 선택/브리지를 넣습니다. 인접한 두 블록을 탭하거나 한 칸 드래그하며, 유효한 이동만 횟수를 소비합니다. 특수 블록은 탭/교환으로 발동합니다. 퍼즐 화면은 가로·세로 한 화면에 맞추고 지도는 전용 영역 안에서 스크롤합니다.
