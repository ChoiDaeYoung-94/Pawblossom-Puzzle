# Pawblossom Puzzle

귀여운 동물 친구들과 함께 숲속 마을을 가꾸는 포근한 매치3 퍼즐 게임입니다.

과일과 자연 소재 블록을 맞추고, 동물 친구들의 부탁을 해결하며 마을을 조금씩 완성해 나갑니다.

## 개발 방향

- **출시 목표:** 한국·미국을 첫 준비 국가로 구글 플레이에 출시
- **게임 언어:** 한국어 기본, 영어 지원 (기존 언어 선택은 유지)
- **분위기:** 따뜻한 색감, 둥근 동물 캐릭터, 부드러운 연출
- **이용자:** 아이부터 중장년까지 편하게 즐길 수 있는 퍼즐을 지향
- **수익화 계획:** 광고와 광고 제거 일회성 결제
- **현재 상태:** 30개 스테이지 초안을 갖춘 플레이 가능한 개발 시제품 (v0.1.7, main 기준)

저장소의 소개와 개발 문서는 한국어로 작성합니다.

![첫 시제품 실제 브라우저 화면](docs/screenshots/prototype-desktop.jpg)

## 실행

Node.js 22 이상을 사용합니다.

PC 이전 후 도구가 PATH에 없으면 [새 PC 환경과 PowerShell 실행 방법](docs/new-pc-environment.ko.md)을 확인해 주세요.

```sh
npm ci
npm run dev
```

브라우저에서 터미널에 표시된 주소를 엽니다. 이웃한 두 블록을 탭하거나 한 칸 드래그하여 매칭합니다. 유효한 이동만 횟수를 소비하며, 4개·5개·T/L 매칭과 특수블록 조합을 지원합니다. 특수 블록은 탭하거나 이웃과 바꾸면 즉시 발동하며 이동을 한 번 씁니다. 가로·세로 게임 화면은 스크롤 없이 맞춥니다.

## 구현된 범위

- 8×8 보드, 연쇄 제거·낙하·힌트·막힌 보드 재배치, 스테이지별 무료 섞기
- 30개 수확 스테이지 초안, 10개 단위 선택, 낙엽 한 겹·두 겹 목표, 첫 완료 별·코인 보상
- 개별 레벨 데이터와 고정 시드 자동 난이도 점검, 초반 3개 스테이지 이동 여유 조정
- 한국어·영어, 설정·완료 기록과 일반 회차의 안정된 보드 로컬 저장·재실행 복원, 손상 저장 보호·복구 사본
- 첫 실행 설명 3단계와 첫 교환 실습, 건너뛰기·설정에서 다시 보기, 안내 확인 여부 저장
- 독자적으로 생성한 숲속 배경·토끼와 핍 성공·격려 결과 아트, 자체 SVG 블록 6종과 정원 0~5단계 아트
- 원본 Web Audio 배경음과 효과음 8종, 개별 음소거·백그라운드 중단·재개 오류 복구
- 보드 키보드 조작·접근성 상태 안내, 터치 취소·다중 입력 보호
- 개발/testing 전용 스테이지 선택과 보상·일반 회차 분리
- Capacitor Android 프로젝트, debug 전용 수동 시험 광고·결제 브리지 (상품 미설정으로 구매 차단)

```sh
npm test
npm run build
npm run build:test
```

Android 빌드에는 Android SDK와 JDK가 별도로 필요합니다. [빌드와 출시 준비](docs/android-release.ko.md)를 참고해 주세요.

운영 광고·광고 제거 결제·상점과 특수블록 실습은 미완료입니다. debug 시험 브리지 구현을 실제 광고·구매·복원 검증이나 운영 수익화 완료로 표시하지 않습니다. Android 실기기·한국/미국 스토어·출시 서명 검증과 최종 콘텐츠·아트 검수가 남아 있습니다.

최신 사용자 지시에 따라 **단말 테스트와 APK 전달은 보류**하고 구현·자동 검사·브라우저 검증을 계속합니다. 나중에 폰을 연결하면 총괄이 설치·입력·저장·복귀·로그를 일괄 점검하고, 사용자님의 최종 감각 검수와 변경 결정 후 후속 구현을 진행합니다.
