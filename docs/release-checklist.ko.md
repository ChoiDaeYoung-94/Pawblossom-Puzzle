우선 첫 플레이·사용성 → 실기기 점검과 사운드 → 출시 콘텐츠·에셋 → 광고·결제 → 스토어 테스트 순서로 진행합니다. 광고 SDK를 선택하기 전에 대상 연령과 출시 국가에 맞는 요구사항을 공식 문서로 확인합니다. 위 목록은 정책 검증을 대신하지 않습니다.
