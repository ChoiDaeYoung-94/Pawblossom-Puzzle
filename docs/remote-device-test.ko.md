# 원격 Android 테스트

연결 이슈: [#12](https://github.com/ChoiDaeYoung-94/Pawblossom-Puzzle/issues/12) · 2026-10-13

사용자님은 회사의 테스트 폰에서 Google Drive APK를 내려받아 확인합니다. 개발 PC에 바로 USB를 연결할 수 있다는 전제로 작업하지 않습니다. 배포 파일은 개인 Drive의 `Pawblossom Puzzle 테스트` 폴더에 관리하며, 다운로드 링크는 사용자님께 직접 전달합니다. 파일을 올린 것과 실기기 검증 완료를 구분합니다.

## 첫 점검 순서

1. 같은 Drive 계정으로 테스트 폰에 로그인하고 APK를 내려받아 설치합니다. 설치 실패 시 표시된 문구와 기기/Android 버전을 기록합니다. 기존 설치와 서명이 다르다는 오류가 나면 기존 앱을 바로 삭제하지 말고 알려 주세요.
2. 첫 실행에서 설명 3단계와 첫 교환 실습을 완료합니다. 뒤로가기·건너뛰기와 설정에서 다시 보기도 확인합니다.
3. 1스테이지의 이동 26회와 딸기 12·당근 10 목표를 확인합니다. 이웃 탭과 네 방향 스와이프를 사용해 플레이합니다.
4. 매치 없는 교환이 이동을 소비하지 않는지, 매치와 연쇄 후 목표가 갱신되는지 확인합니다.
5. 무료 섞기 한 번과 재시작, 성공·실패 후 다음 행동을 확인합니다.
6. 플레이 도중 홈으로 나갔다 복귀하고, 연쇄·안내·결과 화면에서 뒤로가기를 확인합니다.
7. 영어↔한국어, 배경음·효과음 음소거를 바꿉니다. 실제 스피커·이어폰의 음량·피로감·끊김을 기록합니다.
8. 첫 완료 보상과 마을 가꾸기를 확인한 뒤 앱을 종료·재실행하여 완료 기록·보상·설정이 유지되는지 확인합니다. 진행 중 보드는 재실행하면 새로 시작하는 현재 사양입니다.
9. 네트워크를 끊어 다시 실행하고 퍼즐을 진행할 수 있는지 확인합니다.

모두 한 번에 확인할 필요는 없습니다. 설치와 첫 실행의 막힘을 먼저 알려 주시면 우선 수정합니다.
