## 조작·특수블록·진행 설계 제안

- 인접 두 칸 드래그와 탭 후 이웃 탭을 함께 지원합니다. 드래그 방향을 판정하고 보드 해결 중에는 새 이동 입력을 잠급니다. 성립하지 않는 교환은 짧게 복귀하며 남은 이동 횟수를 소비하지 않는 방향을 제안합니다.
- 4개 직선은 줄바람, 5개 직선은 꽃빛, T/L형은 꽃잎 폭죽 같은 창작 모티프를 사용합니다. 실제 게임 코드의 규칙을 확정한 뒤 튜토리얼과 이름을 맞춥니다. 범위 예고, 발동, 제거, 낙하, 연쇄의 순서를 일관되게 유지합니다.
- 목표와 남은 이동을 먼저 읽을 수 있게 배치합니다. 실패 화면은 실패 원인과 재시작을 간단히 안내합니다. 마을 보상은 완료 후에만 주고 저장된 진행과 일치시킵니다.
- 광고는 성공·실패·보상 흐름이 끝난 시점에 검토합니다. 보상형 광고는 선택으로 제시하고 보드 조작 중 끼어들지 않게 합니다. Royal Match의 광고 없는 모델과 Pawblossom의 광고·광고 제거 결제 계획은 다르므로 수익화 방식을 그대로 참고하지 않습니다. [Royal Match 공식 스토어 설명](https://play.google.com/store/apps/details?id=com.dreamgames.royalmatch&hl=en)

## 화면 피드백과 사운드 설계 제안

아래 수치와 음향은 원작을 측정한 값이 아니라 Pawblossom 시제품의 출발점입니다.

| 사건 | 화면 제안 | 원본 합성 효과음 |
| --- | --- | --- |
| 선택·탭 | 짧은 크기 변화와 테두리, 80~120ms | `tap`: 작은 한 음 |
| 교환 성공 / 불가 | 120~180ms 교환 / 원래 칸으로 복귀 | `swap`: 두 음 / `invalid`: 작은 하행 두 음 |
| 매치·연쇄 | 짧은 과일 반짝임, 목표로 이동하는 수확 아이콘 | `match`: 연쇄 단계에 따라 제한적으로 상승 |
| 특수블록 | 범위와 방향을 먼저 읽을 수 있는 잎·꽃 파동 | `special`: 짧은 상승 음형 |
| 완료·보상·실패 | 동물 반응, 숫자 증가, 부담 없는 재시작 | `win`·`reward`·`lose`: 서로 다른 짧은 음형 |

원작 음원의 편성·템포·볼륨·믹스 품질은 이 조사로 확인하지 못했습니다. 포근한 피아노/마림바풍 5음계, 조용한 BGM, 날카로운 충격음을 줄이는 선택은 새 창작 방향입니다. 소리를 꺼도 목표·성공·실패·보상을 시각적으로 이해할 수 있어야 합니다. 자세한 구현과 실기기 검수는 [오디오 방향 문서](audio-direction.ko.md)에 정리했습니다.

## 창작 경계와 후속 검증

원작 이미지·캐릭터·UI 배치·효과음·음악·로고·문구·레벨 배열을 추출하거나 복제하지 않습니다. 위 링크는 기획 근거이며 에셋 다운로드 목록이 아닙니다. Pawblossom의 모든 음형은 이 프로젝트에서 직접 작성하고 Web Audio로 합성합니다.

다음 검증에서는 정식 앱의 초반 흐름을 직접 플레이해 목표 가독성, 입력 대기 시간, 연쇄 동안의 정보 전달을 관찰하되 영상·음원을 에셋으로 전용하지 않습니다. 영어 기본 UI와 한국어 번역의 줄바꿈, 작은 Android 화면, 색각 차이, 무음 플레이도 함께 확인합니다.
